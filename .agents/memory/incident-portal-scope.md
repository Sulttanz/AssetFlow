---
name: Incident portal and external project users
description: Employee linkage, project-scoped incident intake, and staff-only triage boundaries.
---

Treat an account without an employee link as an external/project user. Hide employee-only asset navigation and hardware requests, while retaining its permitted project tickets and service requests.

**Why:** The user explicitly requested that external project users see project ITSM work rather than internal employee hardware options.

**How to apply:** Portal incident intake offers only assigned projects and global or matching-project incident types. Lock a sole assigned project and clearly explain when none is assigned. End users supply subject, description, optional assigned equipment, and attachments; staff retain technical triage. Enforce the same project, catalog, and employee boundaries on the server rather than relying on hidden controls. Preserve an explicitly chosen employee link when editing unrelated account details.
