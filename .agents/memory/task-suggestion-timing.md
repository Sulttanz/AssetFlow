---
name: Task suggestion timing
description: When to bring up suggested follow-up tasks for this project.
---

Do not notify the user about suggested follow-up tasks while their main project tasks are still underway. After the main project tasks are complete, ask whether they want to continue with the suggestions.

**Why:** The user asked to defer follow-up suggestions until their main project tasks are done.

**How to apply:** Keep responses focused on active project work; wait until the main task queue is complete before asking whether to proceed with suggestions.
