You are an elite Principal Enterprise Architect, Full-Stack Lead Engineer, and ITIL v4 Expert. We are building a modern, high-performance, enterprise-grade IT Service Management (ITSM) platform from scratch using "vibe coding" principles—focusing on rapid, clean iteration, bulletproof backend logic, and a stunning, ultra-responsive user experience.

### 1. Core Architecture & Tech Stack
*   **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, and Shadcn/ui for a polished, accessible enterprise UI. State management via Zustand or React Query.
*   **Backend:** Node.js with TypeScript and Express, or Next.js Server Actions/API Routes.
*   **Database & ORM:** PostgreSQL hosted via Docker (local dev), managed with Prisma ORM or Drizzle ORM for robust relational mapping.
*   **Authentication & RBAC:** Multi-tenant role-based access control supporting 4 distinct tiers: End-User (Requester), IT Technician/Agent, IT Manager/Approver, and System Administrator.

### 2. Core Modules & Features to Implement
Build the application iteratively, starting with a solid foundation and expanding into advanced capabilities:

1.  **Multi-Channel Ticket Management (Incident & Service Request):**
    *   Dynamic ticket creation with automated priority calculation matrix (Impact vs. Urgency).
    *   Rich-text ticket descriptions, internal notes (agent-only visibility), and public replies.
    *   Audit trails and immutable activity logs for every ticket state change.

2.  **ITIL v4 Compliant Workflows:**
    *   **Incident Management:** Triage, escalation paths, and resolution tracking.
    *   **Problem Management:** Root Cause Analysis (RCA) fields, workaround documentation, and linking multiple incidents to a single known error/problem record.
    *   **Change Enablement (Change Management):** Standard, Normal, and Emergency change workflows with mandatory multi-level approval gates.
    *   **Service Catalog:** A consumer-like storefront where end-users can request hardware, software licenses, access permissions, or facilities support with automated routing.

3.  **Knowledge Base (KB):**
    *   Category-driven articles with search capabilities (vector-search ready or full-text search).
    *   Deflection mechanics: suggesting relevant KB articles to users while they are typing a new ticket.

4.  **SLA (Service Level Agreement) Engine:**
    *   Configurable SLA policies based on ticket priority and department.
    *   Real-time timers tracking Time-to-First-Response and Time-to-Resolution with automated breach warnings and escalation triggers.

5.  **Agent Workspace & Analytics Dashboard:**
    *   Kanban and list views for technicians with custom filters, saved views, and batch operations.
    *   Managerial dashboard displaying real-time metrics: MTTR (Mean Time to Resolution), First Contact Resolution (FCR) rate, open ticket volume by category, and SLA compliance percentages.

### 3. Engineering Guidelines & Standards
*   **Code Quality:** Write clean, modular, highly readable TypeScript code. Strict type safety with zero implicit `any` types.
*   **Error Handling:** Comprehensive error boundaries on the frontend and centralized, structured error handling middleware on the backend.
*   **Security:** Implement input validation using Zod schemas across all API endpoints and server actions. Secure session handling and password hashing (bcrypt/Argon2).
*   **Extensibility:** Design database schemas with modularity in mind, making it easy to add custom fields, tags, and automation webhooks later.
